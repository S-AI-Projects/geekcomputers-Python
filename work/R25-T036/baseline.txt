Source Analysis (Before Refactoring):
====================================
1. Original Implementation:
   ```python
   a = int(input("Enter number 1 (a): "))
   b = int(input("Enter number 2 (b): "))

   i = 1
   gcd = -1
   while i <= a and i <= b:
       if a % i == 0 and b % i == 0:
           gcd = i
       i = i + 1

   print("\nGCD of {0} and {1} = {2}".format(a, b, gcd))
   ```

Target Responsibility for Simplification:
=========================================
- Responsibility: Common divisor divisibility check `(a % i == 0 and b % i == 0)`.
- Refactoring:
  1. Encapsulate the core linear-search algorithm in `def gcd(a, b) -> int:`.
  2. Extract the common divisor check into a dedicated helper function `is_common_divisor(i, a, b)`
     (and/or explicit named boolean predicate `is_common = (a % i == 0 and b % i == 0)`).
  3. Guard the CLI interactive prompt under `if __name__ == "__main__":` so the function can be
     imported and tested cleanly without blocking on stdin.
- Readability Improvement:
  Separates the semantic condition "is `i` a common divisor of both `a` and `b`" from the loop iteration
  and accumulator state update in `gcd`.
